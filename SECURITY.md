# Security

Please report security problems privately: on this repository's **Security** tab, click **Report a
vulnerability**. That reaches the maintainer without making the problem public.

That includes a release that doesn't match its source or this repository's
[code signing policy](CODE_SIGNING_POLICY.md), a release whose SHA-256 differs from the one listed with it, or a way
for the uploader to read or send anything other than the add-on's saved code.

Only the latest release is supported. Fixes ship as a new release.
